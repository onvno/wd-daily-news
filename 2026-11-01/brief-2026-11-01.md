## 一、今日值得上手 · 2 个

### 1. Agent Desktop（vercel-labs/agent-desktop）
- **一句话亮点**：Vercel 开源的跨平台桌面 Agent 底座，用 Rust 走系统"无障碍树"精准读取和操作任意桌面应用，不靠截屏猜像素，24 小时狂涨 1800+ Star 冲上 GitHub 日榜。
- **它能帮你干什么**：想让 AI Agent 自动填表单、操作本地软件、批量处理桌面端重复工作？它提供稳定的 UI 元素引用和可重试动作，比像素点击方案可靠一个量级，macOS/Windows/Linux 全覆盖。
- **链接**：https://github.com/vercel-labs/agent-desktop

### 2. OpenMontage（calesthio/OpenMontage）
- **一句话亮点**：号称全球首个开源"Agentic 视频生产系统"，12 条生产流水线 + 100+ 工具 + 700+ Agent 技能文件，把你的 Claude Code / Codex 直接变成一支视频制作团队。
- **它能帮你干什么**：不会剪辑也能量产视频——从脚本、分镜、素材、配音到成片全流程交给编码 Agent 跑流水线，适合做短视频矩阵、产品宣传片和知识类内容批量生产。
- **链接**：https://github.com/calesthio/OpenMontage
