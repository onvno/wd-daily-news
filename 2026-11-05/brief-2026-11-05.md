### 1. 腾讯混元 Hy4 正式版 —— 770B 开源旗舰，首次"能看 + 能动手"
- **一句话亮点**：腾讯 11 月 4 日发布混元 Hy4 正式版，参数规模扩到 770B，首次引入视觉理解与电脑操作（Computer Use）能力，正式跻身最强开源模型之列。
- **它能帮你干什么**：Hy4 可结合推理和工具调用处理图像、复杂图表与视觉数学问题，还支持通过命令行 + 图形界面直接操作电脑——已针对 Blender、CAD 等专业软件和跨应用长任务专项训练。在 579 个真实金融任务众测中以 3.04 分居开源第一，自建测试幻觉率从 15.76% 降到 5.45%。模型已上线腾讯云和 OpenRouter，API 价格不变，权重也计划近期开源。
- **链接**：https://www.sohu.com/a/1097287287_455313 （腾讯研究院 AI 速递）

### 2. NVIDIA/auto-ontology —— 给 Agent 装上"会推理的知识图谱"
- **一句话亮点**：NVIDIA 开源的 Python 框架，为数据构建语义化、图谱化的推理层，让 LLM/Agent 的检索更准、查询生成更确定，昨日以 +2053 Star 登顶 GitHub Trending。
- **它能帮你干什么**：如果你的 RAG 或 Agent 项目苦于"检索到的上下文答非所问"，可以用 auto-ontology 在数据之上加一层本体图谱：自动生成确定性查询、让上下文检索更有结构，还能让 Agent 的推理过程更可解释——适合企业知识库、数据问答、Agent 工作流等场景。
- **链接**：https://github.com/NVIDIA/auto-ontology
