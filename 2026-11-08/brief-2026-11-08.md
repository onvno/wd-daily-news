# 互联网 AI 热点简报 · 2026-11-08（周日）

## 一、今日值得上手

### 1. craft-anything —— 把"看懂一个应用"变成"让 Agent 给你重造一个"
- **一句话亮点**：纯 Rust 写的 clean-room 重建引擎，用真实检查工具研究任意网站/App/游戏，再由编码 Agent 用你指定的技术栈重造你的版本，本周暴涨 2 万+ Star（现 20.5K）。
- **它能帮你干什么**：看到喜欢的产品想做个自己的版本？把它指向原站，它只基于"看得见的部分"做净室分析，通过你自己的 Claude Code 出活，314 个工具还能当 CLI 和 MCP 用，支持 macOS / Windows / Linux / Web。注意目前是早期 Alpha。
- **链接**：https://github.com/storytold/craft-anything

### 2. niubigeo —— 你的产品在 AI 助手嘴里是怎么被介绍的？
- **一句话亮点**：自托管的开源 GEO 检测工具，批量测试各家 AI 模型如何描述你的产品——谁被推荐了、品牌被怎么说、引用了哪些来源，日榜 +1200 Star。
- **它能帮你干什么**：做电商/独立产品的都该测一测：输入域名、选几个模型，它跑关键词测试并展示原始回答，帮你搞清自己在中 AI 搜索（GEO）里的真实位置。需要 Node.js 22+ 和自己的 OpenRouter Key。
- **链接**：https://github.com/Albert-Weasker/niubigeo
