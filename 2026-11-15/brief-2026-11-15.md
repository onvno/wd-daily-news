### 2. magpie —— 菜单栏里给所有编程 Agent 随手换模型
- **一句话亮点**：一个本地网关让 Claude Code 跑 Kimi、Codex 跑 DeepSeek、Gemini CLI 跑 GLM，配额用尽自动无感切换下一账号，7 天涨 4.8K Star（总 36K）。
- **它能帮你干什么**：多 Agent 用户最头疼的"一个订阅只能喂一个工具"被解决——菜单栏一键给任意 Agent 指定任意模型/账号，长任务不再因限流中断；请求全走本机网关不经第三方中转，还支持密钥自动脱敏；macOS/Windows/Linux/Docker/Termux 全平台，MIT 开源。
- **链接**：https://github.com/yetone/magpie
