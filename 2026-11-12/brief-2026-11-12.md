### 1. Qwen Code 1.0 —— 阿里把商业级编码 Agent 内核开源了
- **一句话亮点**：阿里把 Qoder 里打磨多年的编码 Agent Harness 以 Apache 2.0 协议开源，"手脑分离"架构把推理编排与工具执行拆开管理，支持多节点、多会话。
- **它能帮你干什么**：给终端里的编码 Agent 换一个可控底座——模型接入、沙箱、MCP 工具统一入口治理，想自建团队级编码智能体又不想从零写执行层的开发者可以直接拿它当骨架。
- **链接**：https://github.com/QwenLM/qwen-code

### 2. OpenDataLoader PDF —— CPU 上每秒解析 100 页的 AI 投喂神器
- **一句话亮点**：开源 PDF 解析器，纯 CPU 每秒处理约 100 页，输出 Markdown/JSON/HTML 且自带边界框坐标，综合基准 0.907 排名第一，登 GitHub Trending 榜首（3 万+ Star）。
- **它能帮你干什么**：给 RAG / 知识库批量喂 PDF——论文、财报、扫描件直接转成 AI 友好的 Markdown，表格、公式、多栏排版都能正确还原，Apache 2.0 完全免费，`pip install opendataloader-pdf` 三行代码接入。
- **链接**：https://github.com/opendataloader-project/opendataloader-pdf （官网：https://www.opendataloader.org ）
