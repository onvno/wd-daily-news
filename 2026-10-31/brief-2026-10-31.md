### 1. Qwenputer —— 把一台 CPU"编译"进大模型权重里

- **一句话亮点**：开发者把完整的 32 位 RISC-V CPU 直接编译进 Qwen3.5-4B 的权重（不训练、不外挂任何工具），模型前向传播内就能跑 C 和 MicroPython，1800 万条指令自由运行零错误。
- **它能帮你干什么**：让 4B 小模型做精确大数运算——NUPA 长整数基准从 48.6% 提到 100%，追平外挂 Python 工具的水平，算数再也不"编数字"；权重即确定性行为，也是 AI 安全研究的理想测试床。一张 24GB 显存的卡就能跑。
- **链接**：https://github.com/divagr18/qwenputer （权重：huggingface.co/divagr1925/Qwen3.5-4B-Qwenputer；详解：https://deniz.in/qwenputer-compiles-a-working-risc-v-cpu-into-the-weights-of-qwen-3-5）

### 2. claude-mem —— 给编码 Agent 装上"跨会话记忆"

- **一句话亮点**：自动捕获 Claude Code 每次会话做过什么，AI 压缩后在下次会话注入相关上下文，重启不"失忆"；兼容 Claude Code / Codex / Gemini CLI / Copilot 等主流编码工具。
- **它能帮你干什么**：长项目连续开发不用每次重新交代背景，Agent 记得你的架构决策、踩过的坑和未完成任务；昨日 GitHub Trending 日增 300+ Star，安装即用。
- **链接**：https://github.com/thedotmack/claude-mem
