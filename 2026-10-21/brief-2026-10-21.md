## 一、今日值得上手 · 2 个

### 1. ai-job-search —— 把整个求职流程交给 Claude Code 跑
- **一句话亮点**：GitHub Trending 日榜第一（总 Star 5.98 万、今日 +3900），一个跑在本地的 AI 求职申请框架：评估职位匹配度 → 定制简历 → 写求职信 → 模拟面试，全流程一条龙。
- **它能帮你干什么**：正在找工作或想跳槽的人，fork 一份到自己账号，把目标职位 JD 喂给它，它会基于 Claude Code 自动产出贴合该职位的简历与求职信，并生成面试准备清单——数据全在本地，不用把个人信息交给第三方求职平台。
- **链接**：https://github.com/MadsLorentzen/ai-job-search

### 2. security-audit-skill —— Cloudflare 官方出品的安全审计技能
- **一句话亮点**：Cloudflare 开源的编码智能体技能（总 Star 3.36 万、今日 +1700），给 Claude Code 等 Agent 装上"多阶段安全审计"能力，产出可独立验证、机器可读的审计结论。
- **它能帮你干什么**：上线前把自己的代码仓库交给它，它会分阶段做系统性安全审计（注入、越权、依赖漏洞等），每条发现都带证据和可验证的结论格式，适合个人项目或小团队在发布前做一轮"免费安全体检"。
- **链接**：https://github.com/cloudflare/security-audit-skill
