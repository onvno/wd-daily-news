## 一、今日值得上手 · 2 个

### 1. Reflection Beam —— 501B 开源权重模型正式可下载
- **一句话亮点**：美国新贵 Reflection 将旗舰模型 Beam（501B 参数 MoE、每 token 激活 23B、1M 上下文）以 Apache 2.0 协议放上 Hugging Face，推理速度堪比 23B 小模型，SWE-bench Verified 81.6%。
- **它能帮你干什么**：想在自有硬件/云上跑一个前沿级编码与 Agent 模型的团队，可直接下载 BF16/FP8/NVFP4 权重，vLLM、SGLang、transformers 首日即支持；没有大卡也可以先用官方免费起步 API 体验，还配套开源终端工具 Mirror CLI。
- **链接**：
  - 模型仓库：https://huggingface.co/reflection/Beam-1.0-501B-A23B
  - 官方博客：http://reflection.ai/blog/beam-is-available

### 2. Agent-Reach —— 给 AI Agent 一键装上"上网能力"
- **一句话亮点**：本周 GitHub 热门（35k+ star，一周新增 8.3k），让 Claude Code、Cursor 等 Agent 一句话接入 YouTube、X、Reddit、小红书等平台。
- **它能帮你干什么**：Agent 默认抓不到主流平台内容，它自动搞定 API 认证、反爬绕过、登录态和数据清洗，装好后你说"帮我看看 Reddit 上大家在讨论什么"就能直接出结果，不用手动折腾配置。
- **链接**：https://github.com/Panniantong/Agent-Reach
