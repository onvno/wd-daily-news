# 互联网 AI 热点简报 · 2026-10-25

## 一、今日值得上手 · 2 个

### 1. Kimi K3.1 Pro（月之暗面）
- **一句话亮点**：3T 级开源旗舰后训练版，Terminal-Bench 4.0 拿下 65.7% 超 GPT-6 Astra，紧追 Claude Opus 5.5，还自带"3D Make"——一句话直接生成可 3D 打印的模型文件。
- **它能帮你干什么**：官方渠道（kimi.ai / Kimi App）现在就能用，100 万 token 上下文适合整库代码分析、长文档调研；3D Make 输入文字或草图即可预览、编辑 3D 模型，下载后可直接 3D 打印或导出视频/Live Photos 分享；权重将于 11 月 4 日全面开源，届时可本地部署。另有 2-3 倍速的 Pro Highspeed 版本。
- **链接**：https://www.kimi.ai/ （官方试用）· 评测详情：https://en.kocpc.com.tw/archives/26578

### 2. 腾讯 WeVisOne-VL（2B / 4B）
- **一句话亮点**：腾讯微信视觉团队开源的"全家桶"视觉模型，一个 API 同时搞定目标检测、OCR、分割、抠图（alpha matting）等 7 类任务，Apache 2.0 协议。
- **它能帮你干什么**：2B 版约 5GB 显存即可本地跑，做电商图处理很实用——商品图批量抠图换背景、图片文字提取、数物体、指哪打哪的指代表达，都能用一个 `model.predict()` 接口完成；基于 Qwen3-VL + 960 万参数像素解码器，30+ 项基准上表现强于同尺寸专用模型。
- **链接**：模型与部署详解：https://aicybr.com/blog/tencent-wevisone-vl-2b-4b-vision-perception-deployment （文内附 GitHub 仓库与 HuggingFace 权重地址）
