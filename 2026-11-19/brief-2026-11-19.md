## 一、【今日值得上手 · 2 个】

### 1. rust-anything（erkamyaman/rust-anything）

- **一句话亮点**：把你的 TypeScript / Python / Go / Java 程序逐块改写成 Rust，全程用"行为录像"回放校验，结果不一致就打回重写，改完行为完全一致。
- **它能帮你干什么**：不用整体重写老项目——先给 CLI、服务或某条热点路径录一段行为，让编码 Agent 逐块翻译成 Rust，工具自动回放录像比对，官方基准显示跑出 3-20 倍提速且结果不变；想让旧项目渐进式提速的开发者今天就能上手。
- **链接**：https://github.com/erkamyaman/rust-anything （GitHub 日榜 +1046 Star）

### 2. Kling Image 4.0（可灵图像 4.0）

- **一句话亮点**：快手深夜发布的新一代图像模型，首次支持原生 8K 出图，单张图最多内嵌 2000 字，内置 70 多款商用字体。
- **它能帮你干什么**：一次描述最多生成 10 张风格统一的系列图，还能直出电商详情页长图——做店铺海报、小红书配图、商品长图不用再手动拼图；图像 API 已同步向企业和开发者开放。
- **链接**：https://www.ithome.com/1/028/563.htm
