## 一、今日值得上手 · 2 个

### 1. Tencent/LoopForge —— 腾讯开源的编码 Agent「交付流水线」，需求进、PR 出
- **一句话亮点**：腾讯轻量云团队开源（MIT），用 SOP 把 CodeBuddy / Codex / Claude Code 编排成「规划→实现→独立评审→测试→交付」的流水线，Docker 沙箱隔离 + 人工审批关口，腾讯内部 20+ 部门月跑 200+ 需求。
- **它能帮你干什么**：如果你已经在用 Claude Code 或 Codex，它补上团队级交付那一层——谁来干、在哪个沙箱、按什么顺序、谁签字，每次运行留节点日志和成本报表；单机 Docker 一条 `./start.sh` 就能自部署，无需改任何 Agent 本体。
- **链接**：https://github.com/Tencent/LoopForge

### 2. Runway Praxis-1 —— 首个全量开源的「世界动作模型」机器人底座（27B / Apache 2.0）
- **一句话亮点**：Runway 昨日兑现承诺，把 27B 机器人世界动作模型 Praxis-1 的权重、推理与微调代码按 Apache 2.0 全量开放，商用无门槛；NVIDIA RoboLab-120 同类第一（46.2%），真实机械臂 100 次任务成功 88 次。
- **它能帮你干什么**：先「看视频预测画面变化」再算机器人动作，一张 RTX 5090 就能跑压缩版（NVFP4 仅 17.5GB），机器人端可上 Jetson Thor；支持 LoRA 微调适配自己的机械臂/相机/任务，机器人方向的研究者和开发者终于有了可自由商用的前沿底座。
- **链接**：https://github.com/runwayml/praxis-1-oss （官方研究页：https://runwayml.com/research/praxis-1-video-pretraining-to-robot-control）
