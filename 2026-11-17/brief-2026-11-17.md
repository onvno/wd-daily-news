## 一、今日值得上手 · 2 个

### 1. Univer —— 给 AI 智能体配的"Office 内核"
- **一句话亮点**：开源 TypeScript SDK，把电子表格、文档、演示三大编辑器装进你自己的产品，近两日以日增 1100+ Star 冲上 GitHub Trending。
- **它能帮你干什么**：做 AI 应用时想让智能体直接读写 Excel/Word/PPT？Univer 同一套 Facade API 既跑浏览器也跑 Node 无头模式，智能体可通过结构化接口操作 Office 文件，Canvas 渲染加专用公式引擎保证大表流畅，不用再依赖微软全家桶。
- **链接**：https://github.com/dream-num/univer

### 2. NVIDIA SkillEvaluator —— Agent 技能的"验货台"
- **一句话亮点**：NVIDIA 开源的技能评估框架（v0.9，11 月 13 日发布），用对照实验回答"装一个 agent 技能到底有没有用、花了多少钱"。
- **它能帮你干什么**：同一个任务跑两遍——一遍带技能、一遍不带，自动对照质量门槛与 token 花费，判断技能收益是否值得开销。团队积攒了一堆 agent 技能说不清哪些该留，或接第三方插件前想先验证收益，它都能派上用场。
- **链接**：https://github.com/NVIDIA/SkillEvaluator
